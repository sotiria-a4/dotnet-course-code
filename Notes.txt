Model Mapping

We are gonna use a new library to our project called Automapper.

dotnet add package AutoMapper

TI EINAI TO MODEL MAPPING
- Metafora timwn apo ena model se ena allo model.
- Xreiazetai otan ta dedomena erxontai me alli morfi apo auti pou theloume.
  Px to JSON exei computer_id, video_card (snake_case) -> ComputerSnake
  enw to programma mas doulevei me ComputerId, VideoCard -> Computer.
- Anti na grafoume me to xeri ComputerId = snake.computer_id gia kathe pedio,
  dinoume kanones sto AutoMapper kai kanei autos tin antigrafi.

TI KANEI TO KATHE KOMMATI
Mapper mapper = new Mapper(new MapperConfiguration((cfg) => {
    cfg.CreateMap<ComputerSnake, Computer>();
}));
- MapperConfiguration = OI KANONES (apo poio model se poio).
- Mapper = AUTOS POU EFARMOZEI tous kanones.
- cfg = to antikeimeno sto opoio grafoume tous kanones.
- (cfg) => { ... } = lambda, mia mikri synartisi xwris onoma.
  Ti dinoume sto AutoMapper kai auti ti trexei otan ftiaxnei to configuration.

CreateMap<1o, 2o>
- 1o = SOURCE, apo pou PAIRNOUME tis times (ComputerSnake).
- 2o = DESTINATION, pou tis GRAFOUME (Computer).
- I seira exei simasia: antigrafi mono apo to 1o sto 2o.

PROSOXH
- To CreateMap antigrafei mono osa onomata tairiazoun (xwris na koitaei
  pezo/kefalaia): motherboard -> Motherboard, price -> Price.
- Me _ den tairiazoun: computer_id, video_card thelei ForMember,
  alliws menoun me tin default timi, xwris error:
  .ForMember(dest => dest.VideoCard, opt => opt.MapFrom(src => src.video_card))
- Afou ftiaxtei o mapper, h antigrafi ginetai me mapper.Map<...>(...).

TI KANEI TO ForMember
- Leei sto AutoMapper: "auto to pedio tou destination na parei tin timi tou
  apo ekeino to pedio tou source".
- To xreiazomaste otan ta onomata diaferoun kai o AutoMapper den ta vriskei monos tou.
- Ena ForMember gia kathe tetoio pedio, kai to ; MONO sto telos tis alysidas.

.ForMember(destination => destination.ComputerId,              // poio pedio GEMIZOUME (Computer)
    options => options.MapFrom(source => source.computer_id))  // apo poio pedio DIAVAZOUME (ComputerSnake)

κείμενο JSON  --Deserialize-->  ComputerSnake  --Map-->  Computer

MODEL MAPPING vs JSONPROPERTYNAME

1. VASIKH DIAFORA

Deserialize = JSON text → C# object.
Serialize = C# object → JSON text.
Mapping = Metafora timwn apo ena C# object se ena allo C# object (synithws diaforetikis klasis).
AutoMapper = Library pou kanei automata to mapping metaxy objects.
JsonPropertyName = Attribute pou leei sto System.Text.Json poio JSON key antistoixei se ena C# property.

PROSOXH: Mapping einai h diadikasia. AutoMapper einai to library pou kanei automata auth th diadikasia.


2. POTE XRHSIMOPOIW JsonPropertyName

To xrhsimopoioume otan ta onomata sto JSON den tairiazoun me ta properties tis C# klasis mas.

Px JSON:

{
  "computer_id": 1,
  "video_card": "RTX 2060"
}

C# Model:

using System.Text.Json.Serialization;

public class Computer
{
    [JsonPropertyName("computer_id")]
    public int ComputerId { get; set; }

    [JsonPropertyName("video_card")]
    public string VideoCard { get; set; }
}

Deserialize:

Computer? computer =
    JsonSerializer.Deserialize<Computer>(json);

TI KANEI TO JsonPropertyName:
- "computer_id" = to akrives onoma tou key sto JSON.
- ComputerId = to property tis C# pou tha parei tin timi.
- Den xreiazomaste ComputerSnake oute AutoMapper.
- Douleuei kai antistrofa sto Serialize: ComputerId → "computer_id".

PROSOXH: To Newtonsoft DEN koitaei to [JsonPropertyName].
Ekei xrisimopoioume [JsonProperty("computer_id")].


FLOW:
JSON → Deserialize → Computer

ALLOS TROPOS GIA snake_case, xwris attribute se kathe pedio:

new JsonSerializerOptions { PropertyNamingPolicy = JsonNamingPolicy.SnakeCaseLower }


3. POTE XRHSIMOPOIW MAPPING / AUTOMAPPER

Mapping kanoume otan exoume hdh ena C# object kai theloume na metatrepsoume ta dedomena tou se ena allo C# object.

Px:
ComputerSnake = Model pou exei ta onomata tou JSON (snake_case).
Computer = Model pou xrisimopoiei to programma mas (PascalCase).

FLOW:
JSON → Deserialize → ComputerSnake → AutoMapper → Computer

GENIKH AKOLOUTHIA STON KWDIKA:

Vima 1. Diavazoume to JSON
string json = File.ReadAllText("ComputersSnake.json");

Vima 2. Kanoume Deserialize se ComputerSnake
IEnumerable<ComputerSnake>? computersSystem =
    JsonSerializer.Deserialize<IEnumerable<ComputerSnake>>(json);

Twra exoume C# objects typou ComputerSnake.

Vima 3. Ftiaxnoume ton mapper kai orizoume tous kanones
Mapper mapper = new Mapper(new MapperConfiguration((cfg) =>
{
    cfg.CreateMap<ComputerSnake, Computer>()
        .ForMember(
            dest => dest.ComputerId,
            opt => opt.MapFrom(src => src.computer_id))
        .ForMember(
            dest => dest.VideoCard,
            opt => opt.MapFrom(src => src.video_card));
            etc. gia ola ta pedia
}));

CreateMap<ComputerSnake, Computer>() = Apo poio model se poio model kanoume mapping.
ForMember = Orizoume xeirokinhta poio property tou destination tha parei timh apo poio property tou source.
Xreiazetai otan o AutoMapper den mporei na antistoixhsei monos tou ta properties.


Vima 4. Kanoume Mapping

if (computersSystem != null)
{
    IEnumerable<Computer> computerResult =
        mapper.Map<IEnumerable<Computer>>(computersSystem);
}

TI KANEI to MAP:
- computersSystem = SOURCE, ta arxika objects (ComputerSnake).
- <IEnumerable<Computer>> = DESTINATION TYPE, se ti theloume na metatrapoun.
- computerResult = Metavliti pou apothikeuei ta nea objects.
- Map<Computer> = Metatrepei ena object.
- Map<IEnumerable<Computer>> = Metatrepei mia syllogi apo objects.

PROSOXH: O AutoMapper den xrisimopoiei automata ta [JsonPropertyName] attributes. Exei dikous tou kanones mapping.

SYNCHRONOUS vs ASYNCHRONOUS PROGRAMMING (async / await)

1. ORISMOI

Synchronous (sygxroni ektelesi):
O kwdikas ekteleitai me ti seira. Kathe ergasia prepei na oloklirwthei prin ksekinisei i epomeni.
Oso mia ergasia perimenei, to thread paramenei mplokarismeno.

Asynchronous (asygxroni ektelesi):
Otan mia ergasia perimenei kati (vasi, diktyo, arxeio, xrono), to thread apeleftherwnetai kai mporei na kanei alli douleia.
Otan i anamoni teleiwsei, i ergasia synexizei apo to simeio pou eixe stamatisei.

PROSOXH: Asynchronous den simainei aparaitita pio grigoro oute parallilo. Simainei oti den spatalame to thread oso perimenoume.


2. VASIKES ENNOIES

Thread = I "grammi ektelesis" pou trexei ton kwdika.
Task = Antikeimeno pou antiproswpevei mia ergasia i opoia tha oloklirwthei sto mellon.
Task<T> = Task pou epistrefei timi typou T otan oloklirwthei.
async = Dilwnei oti i methodos mporei na xrisimopoiei await. Apo mono tou den trexei kwdika se allo thread.
await = Perimenei na teleiwsei ena Task xwris na mplokarei to thread. O ypoloipos kwdikas tis methodou ekteleitai meta.


3. Thread.Sleep vs Task.Delay

Thread.Sleep(100)       : Synchronous. Mplokarei to thread gia 100 ms.
await Task.Delay(100)   : Asynchronous. Perimenei 100 ms xwris na mplokarei to thread.


4. PARADEIGMA

static void ConsoleAfterDelay(string text, int delayTime)
{
    Thread.Sleep(delayTime);
    Console.WriteLine(text);
}

static async Task ConsoleAfterDelayAsync(string text, int delayTime)
{
    await Task.Delay(delayTime);
    Console.WriteLine(text);
}

Task secondTask = ConsoleAfterDelayAsync("Task 2", 150);   // ksekinaei AMESWS
ConsoleAfterDelay("Delay", 101);                           // mplokarei ti Main gia 101 ms
Task thirdTask = ConsoleAfterDelayAsync("Task 3", 50);     // ksekinaei META to Delay
await secondTask;                                          // i Main perimenei to Task 2
await thirdTask;                                           // i Main perimenei to Task 3

- To Task ksekinaei otan kaloume ti methodo, oxi otan grafoume await.
- To await kathorizei pou tha perimenei i Main, oxi pote tha treksei to Task.
- Ta Task trexoun taftoxrona, opote i seira eksodou eksartatai apo tous xronous.
  Me kontinous xronous (px 100 kai 101 ms) i seira mporei na allaksei apo ektelesi se ektelesi.


5. new Task vs Task.Run

Task firstTask = new Task(() => { ... });
firstTask.Start();

- To new Task apla dimiourgei to Task. Den trexei mexri na kalesoume Start().
- Stin praksi protimame to Task.Run(() => { ... }), pou to dimiourgei kai to ksekinaei mazi.


6. GIATI XREIAZETAI TO await STI MAIN

Xwris await, i Main mporei na teleiwsei prin oloklirwthoun ta Task.
Otan teleiwsei i Main, termatizei to programma kai ta Task pou trexoun akomi diakoptontai.
Gia na xrisimopoiisoume await, i Main prepei na einai: static async Task Main(string[] args)


7. KANONES

- Mia async methodos epistrefei Task i Task<T>.
- Apofevgoume to async void (ektos apo event handlers).
- Oi async methodoi syniithws teleiwnoun se Async (px ConsoleAfterDelayAsync).
- Apofevgoume ta .Result kai .Wait(), giati mplokaroun to thread. Xrisimopoioume await.
- async xwris await sti methodo: warning CS1998 kai i methodos trexei sygxrona.
- To async/await einai idaniko gia anamones (I/O): vasi, API, arxeia.
- Gia vari douleia epeksergasias (CPU) xrisimopoioume Task.Run.


8. NA TO THYMAMAI

Synchronous = perimenw kai to thread menei mplokarismeno.
Asynchronous = perimenw kai to thread einai eleuthero gia alli douleia.
Task = i ergasia.
async = i methodos mporei na perimenei.
await = perimene edw mexri na teleiwsei to Task, xwris na mplokareis to thread.

3. INNER JOIN vs LEFT JOIN

FROM TutorialAppSchema.Users AS Users
    INNER JOIN TutorialAppSchema.UserSalary AS UserSalary
        ON UserSalary.UserId = Users.UserId
    LEFT JOIN TutorialAppSchema.UserJobInfo AS UserJobInfo
        ON UserJobInfo.UserId = Users.UserId

- ON = i synthiki pou leei poia grammi tou enos pinaka tairiazei me poia tou allou.

INNER JOIN = Krataei MONO tis grammes pou yparxoun KAI stous 2 pinakes.
             Xristis xwris misthos -> DEN emfanizetai katholou.

LEFT JOIN  = Krataei OLES tis grammes tou aristerou pinaka (Users),
             akoma kai an den yparxei antistoixia sto deksi (UserJobInfo).
             Xristis xwris JobInfo -> emfanizetai, me JobTitle kai Department = NULL.

STO DIKO MAS QUERY:
- Emfanizontai mono oi xristes pou exoun misthos (INNER JOIN me UserSalary).
- Apo autous, osoi den exoun JobInfo emfanizontai me NULL sto JobTitle kai Department (LEFT JOIN).

Px:
Users:        1 Maria, 2 Nikos, 3 Eleni
UserSalary:   1 -> 5000, 3 -> 4000
UserJobInfo:  1 -> Developer

Apotelesma:
1 | Maria | Developer | 5000
3 | Eleni | NULL      | 4000
(o Nikos leipei giati den exei misthos)

PROSOXH: Sto SELECT exoume 2 stiles me onoma UserId (Users.UserId kai UserSalary.UserId).

4. WHERE KAI ORDER BY

WHERE Users.Active = 1        -> mono energoi xristes (Active einai BIT: 1 = true, 0 = false).
ORDER BY Users.UserId DESC    -> taksinomisi apo to megalytero UserId sto mikrotero.
                                 ASC = apo to mikrotero sto megalytero (to default).

SEIRA EKTELESIS (oxi seira grafis):
FROM / JOIN -> WHERE -> SELECT -> ORDER BY
Gi' auto sto ORDER BY mporw na xrisimopoiisw alias tou SELECT, enw sto WHERE oxi.


5. DELETE ME BETWEEN

DELETE FROM TutorialAppSchema.UserSalary WHERE UserId BETWEEN 250 AND 750

- To BETWEEN periexei KAI ta 2 akra: 250 kai 750 diagrafontai kai auta.
- Isodynamo me: WHERE UserId >= 250 AND UserId <= 750
- 750 - 250 + 1 = 501 grammes (an ola ta UserId yparxoun).

PROSOXH: To DELETE den exei undo. Prwta trexw to idio WHERE me SELECT,
blepw ti tha svistei, kai meta allazw to SELECT se DELETE.
Gi' auto to exoume se sxolio (--).


6. EXISTS

SELECT [UserSalary].[UserId],
       [UserSalary].[Salary]
FROM TutorialAppSchema.UserSalary
WHERE EXISTS (
    SELECT * FROM TutorialAppSchema.UserJobInfo AS UserJobInfo
    WHERE UserJobInfo.UserId = UserSalary.UserId)
    AND UserId <> 7

- Gia KATHE grammi tou UserSalary rwtaei:
  "Yparxei toulaxiston mia grammi sto UserJobInfo me to idio UserId?"
- NAI -> i grammi emfanizetai. OXI -> den emfanizetai.
- To EXISTS epistrefei mono true / false. Den fernei stiles apo to UserJobInfo.
  Gi' auto to SELECT * mesa tou den paizei rolo (to idio kai me SELECT 1).
- Stamataei sto prwto tairiasma, den psaxnei tis ypoloipes grammes.
- To subquery xrisimopoiei timi apo to eksoteriko query (UserSalary.UserId).
  Auto legetai correlated subquery.
- AND UserId <> 7 = epipleon synthiki tou eksoterikou WHERE: na min einai o xristis 7.
  <> simainei "diaforo" (to idio me !=).
- Edw o pinakas den exei alias (AS), ara to onoma tou UserSalary leitourgei ws onoma.


7. EXISTS vs INNER JOIN

To antistoixo me JOIN:

SELECT UserSalary.UserId, UserSalary.Salary
FROM TutorialAppSchema.UserSalary AS UserSalary
    INNER JOIN TutorialAppSchema.UserJobInfo AS UserJobInfo
        ON UserJobInfo.UserId = UserSalary.UserId

EINAI TO IDIO? OXI pantote.
- An kathe UserId yparxei MIA fora sto UserJobInfo: idio apotelesma.
- An ena UserId yparxei 2 fores sto UserJobInfo:
    EXISTS     -> o xristis emfanizetai 1 fora.
    INNER JOIN -> o xristis emfanizetai 2 fores (diples grammes).

POTE TO KATHE ENA:
EXISTS     : Thelw grammes tou enos pinaka pou EXOUN antistoixia ston allo.
             Den xreiazomai stiles apo ton allo pinaka.
INNER JOIN : Thelw na SYNDYASW dedomena kai apo tous 2 pinakes.
NOT EXISTS : To antitheto. Grammes pou DEN exoun antistoixia (px misthoi xwris JobInfo).


8. UNION vs UNION ALL

SELECT [UserId], [Salary] FROM TutorialAppSchema.UserSalary
UNION ALL
SELECT [UserId], [Salary] FROM TutorialAppSchema.UserSalary

- Enwnei ta apotelesmata 2 SELECT se enan pinaka, to ena KATW apo to allo.
  (To JOIN enwnei stiles DIPLA-DIPLA, to UNION grammes TI MIA KATW APO TIN ALLI.)

UNION     = afairei tis diples grammes (kanei DISTINCT). Pio argo, giati prepei na sygkrinei.
UNION ALL = krataei OLES tis grammes, kai tis diples. Pio grigoro.

STO DIKO MAS PARADEIGMA (o idios pinakas 2 fores):
UNION     -> kathe grammi emfanizetai 1 fora (oi diples svinontai).
UNION ALL -> kathe grammi emfanizetai 2 fores.

KANONES:
- Kai ta 2 SELECT prepei na exoun ton idio arithmo stilwn, me symvatous typous, me tin idia seira.
- Ta onomata twn stilwn ta pairnei apo to prwto SELECT.
- ORDER BY mpainei mono mia fora, sto telos.


9. INDEXES (EYRETIRIA)

Ti einai: Mia domi pou voithaei ti vasi na vriskei grammes grigora,
xwris na diavazei olo ton pinaka (table scan).
San to eyretirio sto telos enos vivliou.

Kostos: Ta SELECT ginontai pio grigora, alla ta INSERT / UPDATE / DELETE pio arga,
giati prepei na enimerwnetai kai to index. Pianei kai xwro.

CLUSTERED INDEX
CREATE CLUSTERED INDEX cix_UserSalary_UserId ON TutorialAppSchema.UserSalary(UserId)
- Taksinomei tis IDIES tis grammes tou pinaka me vasi to UserId.
- San tilefwnikos katalogos: ta dedomena einai idi me ti seira.
- MONO ENA ana pinaka (oi grammes mporoun na einai taksinomimenes me enan mono tropo).
- To PRIMARY KEY dimiourgei synithws aftomata clustered index.
  An o pinakas exei idi clustered index, to CREATE CLUSTERED INDEX apotygxanei.

NONCLUSTERED INDEX
CREATE NONCLUSTERED INDEX ix_UserJobInfo_JobTitle ON TutorialAppSchema.UserJobInfo(JobTitle)
    INCLUDE (Department)
- Ksexwristi domi, taksinomimeni me to JobTitle, pou deixnei pou einai i kathe grammi.
- Mporoume na exoume POLLA ana pinaka.
- INCLUDE (Department) = apothikeuei mesa sto index kai to Department.
  Ena query pou zitaei JobTitle + Department apantietai MONO apo to index,
  xwris na paei ston pinaka. Auto legetai covering index.

FILTERED INDEX
CREATE NONCLUSTERED INDEX fix_users_Active ON TutorialAppSchema.Users(Active)
    INCLUDE ([Email], [FirstName], [LastName])
    WHERE Active = 1
- Index pou periexei MONO tis grammes pou tairiazoun sto WHERE (energoi xristes).
- Pio mikro kai pio grigoro apo ena index se olo ton pinaka.
- Voithaei queries pou exoun idio filtro, opws to diko mas: WHERE Users.Active = 1.
- An to query zitaei kai stiles pou DEN einai sto INCLUDE (px Gender),
  i vasi prepei na paei kai ston pinaka gia autes.

ONOMATA (convention):
cix_ = clustered index, ix_ = (nonclustered) index, fix_ = filtered index.
Morfi: prothema_Pinakas_Stili, px ix_UserJobInfo_JobTitle.

PROSOXH: Ena CREATE INDEX trexei mia fora. An to ksanatrekso, vgazei error oti yparxei idi.


10. NA TO THYMAMAI

INNER JOIN = mono oi grammes pou tairiazoun kai stous 2 pinakes.
LEFT JOIN  = oles oi grammes tou aristerou, NULL opou den yparxei antistoixia.
EXISTS     = "yparxei antistoixia?" -> filtrarei, kathe grammi mia fora.
UNION      = grammes apo 2 queries, xwris diples.
UNION ALL  = grammes apo 2 queries, me tis diples.
BETWEEN    = periexei kai ta 2 akra.
Clustered index    = taksinomei ton idio ton pinaka, mono 1.
Nonclustered index = ksexwristo eyretirio, polla.
INCLUDE            = epipleon stiles mesa sto index, gia na min paei ston pinaka.
Filtered index     = index mono gia tis grammes tou WHERE.
